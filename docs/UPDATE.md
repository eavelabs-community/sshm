# 🔄 自动更新功能说明

SSH Manager 内置自动检查更新与一键更新能力。

## 功能特性

### ✅ 已实现

1. **静默版本检查**
   - 每次运行命令时自动检查更新（`update` 命令除外）
   - 24 小时缓存，避免频繁请求
   - 发现新版本时在命令执行前友好提示
   - 不干扰正常使用

2. **手动更新命令**
   - `sshm config update`：检查并更新到最新版本
   - `sshm config update --check`：仅检查更新，不执行更新
   - `sshm config update --force`：强制检查，忽略缓存

3. **版本比较**
   - 自动解析语义化版本号
   - 准确判断版本新旧

4. **自动下载**
   - 显示下载进度
   - 支持断点续传

5. **跨平台支持**
   - Windows：自动替换可执行文件
   - Linux/macOS：直接替换或提示使用 sudo

## 使用方法

### 1. 查看当前版本

```bash
sshm --help
# 帮助头部会显示当前版本号
```

### 2. 仅检查更新

```bash
sshm config update --check

# 强制检查（忽略缓存）
sshm config update --check --force
```

### 3. 更新到最新版本

```bash
sshm config update
```

**执行流程：**

1. 检查是否有新版本
2. 显示更新内容（版本号、发布时间、更新说明）
3. 询问确认
4. 下载新版本
5. 自动替换可执行文件

### 4. 静默检查（自动）

每次运行任意命令时，程序会自动检查更新：

```bash
sshm key list

# 如果有新版本，会在输出前显示提示：
# 💡 有新版本可用: v0.0.6 (当前: v0.0.5)
#    运行 'sshm config update' 更新到最新版本
```

## 注意事项

- 更新过程会替换当前正在运行的可执行文件，请确保在非关键任务时执行
- 如果网络受限无法访问 GitHub，可手动前往 Releases 页面下载
- 更新不会影响 `~/.ssh` 目录下的密钥与配置文件
